GearBeacon — START HERE
=======================

GearBeacon is a private, browser-based monitor that runs on your own Windows,
macOS, Linux, NAS, home server, or Docker host. It has no public account or
hosted GearBeacon database.

Requirements
------------
Node.js 22.13 or newer, or Docker.

One-computer launch
-------------------
Windows: double-click run-windows.bat
macOS/Linux: ./run-mac-linux.sh

Open http://localhost:8787. This safe default listens only on your computer.

Offline demo
------------
Windows: double-click run-mock-windows.bat
macOS/Linux: ./run-mock-mac-linux.sh

Private LAN/VPN server
----------------------
Windows: double-click run-private-windows.bat
macOS/Linux: ./run-private-mac-linux.sh

The first start prints a one-time setup token. Enter it in the dashboard and
create the private owner password. Use a trusted LAN/VPN, or put GearBeacon
behind an HTTPS reverse proxy before crossing an untrusted network.

Docker
------
docker compose up -d --build
docker compose logs gearbeacon

Compose publishes only to host loopback by default. The logs show the one-time
owner setup token. SQLite data persists in the gearbeacon-data volume.

Data safety
-----------
Settings includes validated backups, encrypted export, restore preview/import,
update checks, notification preferences, owner sessions, and outbound-connection
visibility. Credentials and sessions are never included in application exports.

Automated verification
----------------------
node --no-warnings scripts/self-test.mjs

See README.md and deploy/README.md for every environment variable and deployment
pattern.
